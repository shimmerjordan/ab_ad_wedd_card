# 🌾 星露谷婚礼请帖 · Stardew Wedding Invitation

一份**可以玩的**婚礼电子请帖：星露谷(Stardew Valley)像素风小游戏，纯前端单文件，零构建零依赖。

宾客在游戏里操控新郎/新娘走动、跳跃、种菜、接水浇灌、施肥、钓鱼、交易，
逐步解锁请帖内容，最终在**婚礼殿堂**完成仪式、找到自己的喜宴桌位。

## ⚙️ 自定义

### 基础信息
编辑 `js/config.js` 里的 `CONFIG`：姓名、日期、地点、电话、邀请函文案、流程、剧情分支台词。

新增可配置项（同在 `js/config.js`）：
- `wishWall`：亲友祝福墙 —— `show`(开关)、`title`、`messages:[{from,text}]`，显示在完整请帖与博物馆留言簿。
- `anniversaries`：纪念日彩蛋 `[{date:'MM-DD', text}]`，当天(现实日期)访问弹专属回忆。
- `toastLines`：终章逐桌敬酒的祝福语，会自动与该桌宾客名拼接。

### 婚礼回执 RSVP（统计来宾·零后端）
完整请帖里内置「📝 填写回执」卡片，用第三方问卷平台收集 **贵姓 / 来宾人数 / 祝福(选填)**，来宾免登录提交，你在平台后台看实时汇总并导出 Excel：
1. 去 **金数据 `jinshuju.net`** / **腾讯问卷 `wj.qq.com`** / **问卷星 `wjx.cn`** 免费建一个表单（建议字段：贵姓、来宾人数、祝福的话）；
2. 发布后复制表单的**分享链接**，粘贴到 `js/config.js → CONFIG.rsvp.url`；
3. 完成。`rsvp.embed=true` 时优先页面内嵌（iframe），平台禁止内嵌会自动改为新窗口打开；`url` 留空则该卡片显示配置提示、不影响来宾。

### DEBUG 模式（博物馆展品 / 桌位表 / 记忆碎片 / 任务直达）
1. 游戏内点 ⚙ 设置，**连点版本号 10 下**进入 DEBUG（版本号旁出现「退出 DEBUG」按钮）
2. 可视化编辑：🖼 博物馆展品（1-4 上墙挂画区，5-12 中央玻璃展柜）、🪑 桌位表（`姓名,桌号` 每行一位，桌号 1-15）、💫 记忆碎片
3. **任务直达**：DEBUG 面板有 Q0~Q5/礼成 按钮，一键跳到任意章节（自动补齐道具与 NPC 位置），殿堂大门也不再锁
4. 配置保存在本机浏览器；点 **⬇ 导出配置 JSON** 得到 `wedding-config.json`，与 `index.html` 一起部署宾客即可读到
5. 桌位编辑器为每位宾客生成**专属分享链接**（一键复制）

### 个人照片（博物馆展品/记忆碎片配图）
照片放进 **`assets/imgs/`**，配置里图片字段直接填**文件名**（如 `合照.jpg`）。
也支持完整 URL 或在 DEBUG 编辑器里上传转存。界面素材在 `assets/elem/`，两者互不干扰。

### 婚纱照点开看大图（全屏 · 可放大到 200% · 不许下载）
这几处照片点一下就**全屏**看原图（无边框衬底，只有照片和深色底），**看得见、放得大、但拿不走**：

| 位置 | 配置字段 | 灯箱 |
|---|---|---|
| 星露谷版·请帖顶部主婚纱照 | `archPhoto` | `#lightbox` |
| 星露谷版·殿堂婚纱照展板（走过去按 A） | `hallPhotos[i].img` | `#lightbox` |
| 老登版·开头主婚纱照 | `luxHero` | `#luxBox` |
| 老登版·浮光剪影画廊 | `hallPhotos[i].img` | `#luxBox` |

新人头像与合照沿用同一套灯箱。图片字段留空则不出现「点开」入口，不给假按钮。

**怎么缩放**（`attachZoom()` 见 `js/invite.js`）：贴边显示算 100%，**上限 200%**（`ZOOM_MAX`）。
- 手机：双指捏合、双击；电脑：滚轮、双击
- 放大后可拖动查看，`panLimit()` 保证图片边缘不会被拖进屏幕露出空隙
- 未放大时轻触/单击关闭；已放大时轻触先缩回贴边（免得手滑关掉），✕ 与 Esc 随时可关
- 缩放时底部短暂浮现倍数（`100%`~`200%`），到顶了看得见
- 浏览器**原生**捏合是没有上限的，所以照旧关掉（`touch-action:none` + 拦 `gesture*`/多指 `touchmove`），倍数全由 `zoomClamp()` 自己算——这是能卡住 200% 的唯一办法
- 转屏或手机地址栏收放会触发 `resize`，此时**只重新夹一次位移、不重置倍数**，否则宾客刚放大就被弹回贴边

**怎么挡住下载**（`lockMedia()` 见 `js/invite.js`，配套 CSS 见 `style.css` 的「不许下载」段）：
- 禁右键菜单、禁拖拽；照片本身 `pointer-events:none`，长按落在外层框上，浏览器给不出「图片另存为」
- 点击与所有缩放手势都绑在**外层容器**上，所以 `pointer-events:none` 不影响点开与捏合
- ⚠️ **前端只挡得住「顺手保存」**：开发者工具、抓包、截屏挡不住（图片终究要下发到浏览器）。不能外流的照片就不要放进请帖
- 例外：通关**分享图** `.share-img` 不受限制，仍可长按保存/下载——那张本来就是给宾客转发的

截图调试钩子：`?show=big`（摊开星露谷灯箱）、`?show=photo`（殿堂展板浮层）、`?lux=1&big=1`（摊开老登版灯箱）；
再加 `&zoom=300` 可验证上限（请求 300% 实际渲染 `scale(2)`、倍数显示 `200%`）。

### 宾客桌位 GET 参数
- 自包含：`index.html?gn=张三&gt=3`（姓名+桌号直接进链接，无需配置文件）
- 查表式：`index.html?g=张三`（需部署 `wedding-config.json`）

宾客打开链接：标题屏显示欢迎横幅，殿堂内对应桌子金色高亮，最终请帖附桌位卡。

## 🛠 技术
Canvas 2D 像素渲染（spritesheet + 程序化绘制混合），Web Audio 实时合成 8-bit BGM 与音效，
多场景引擎（户外 + 博物馆/殿堂/矿洞 3 内景），移动端虚拟摇杆。
中文像素字体 **Fusion Pixel 自托管**于 `assets/fonts/`（此前 jsDelivr `@fontsource` 无中文子集、中文会回退系统字体，已修复；国内可靠、离线可用）；优雅版衬线 Noto Serif SC 走 CDN，失败回退系统宋体。
**PWA**：`manifest.json` + `sw.js`，首访后离线可用、可添加到主屏。
素材图加载失败时自动回退到内置程序化像素画，离线/file:// 也能玩。
